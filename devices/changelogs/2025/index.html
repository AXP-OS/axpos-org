      2025-12.1

      SectionComment
      🪩AXP.OS patch level: 2025-12-05, based on ASB 2025-12-05
      🪩Preparations for A15 move
      🎁All app updates and their versions can be found at build tag 2025-12.1
      🪩Website adjustments to split properly between flavors
      🪩Disable force-encryption on low-end devices (see #162) - note: removing encryption requires to format user data
      🪩Support added for AVB v1.0*
      🪩Support bootloader re-lock on cheeseburger - see #177
      🪩Support bootloader re-lock on dumpling - see #154
      🪩Added a self-hosted AXP.OS Connectivity / Captive Portal Check - see privacy policy
      🪩AXP.OS flavor symbolism changed to ⚙️ (Pro) and 🛡️ (Slim) to better reflect their use cases.
      🪩Updated AXP.OS About info for a better understanding
      🪩Updated AXP.OS milestone timeline for celebrating 🎉
      🪩🚨EOL for Android 9 + 10 ASB patching (ASB backporting to these versions is becoming increasingly impossible), kernel updates are not affected
      💡
      *AVB v1.0 is splitted into 2 parts: boot signing/verification and dm-verity (checksum verification of critical partitions).
      The boot verification is part of the bootloader and so widely independent from the used/flashed Android version but is required for re-locking such a device (e.g. cheeseburger + dumpling).
      dm-verity on the other hand requires the kernel to mount partitions in a specific manner and this requires Android 10 or lower as the relevant code has been removed in Android 11.
      In other words AVB v1.0 is useless on A11 and later.

      Magisk (Pro flavor)

      To fix the endless-request-loop you need to

      1. Open Magisk
      2. let it download the app
      3. Open Magisk once again:
        • you will still see the infamous request about “Additional requirements need to be installed”
        • choose yes to allow this installation once again
        • the device will auto-reboot
        • 🚨WARNING🚨 if you get asked to PATCH the boot image (see the screenshot in “Never PATCH/INSTALL Magisk when asked”) STOP here, then the new fix does not work for you
      4. once rebooted: open Magisk again.. no popup should be shown anymore! 🎉

      F-Droid

      Two AXP.OS F-Droid repositories have been prepared which will receive several apps in the future. Main purpose is deploying out-of-band updates, e.g. for the System Webview but also provide apps build/made by the AXP.OS project. See issue #98 for details and process. At the moment of writing there is only the AOSmium Browser available while this will change during the next weeks when the CI/CD scripts will be extended to push builds also to the F-Droid repos.

      There are 2 repos available: Stable (roughly tested) and Cutting Edge (fully untested). If you enable Cutting Edge be aware that it may contain unstable/broken/incomplete applications (however, you can choose which repository you prefer for each application).

      In order to receive the new AXP.OS repositories you can either reset the F-Droid app or add it manually.

      Important

      Due to a config mistake all Slim builds will receive this update with the next build first but don’t worry you can still add them manually!

      Manually:

      1. Stable:
        • open https://apps.axpos.org/repo/ and scan the code from your phone
      2. Cutting Edge:
        • open https://cutting-apps.axpos.org/repo/ and scan the code from your phone

      By resetting F-Droid:

      1. long press the F-Droid icon
      2. choose App info
      3. choose Storage & Cache
      4. choose Clear Storage (Cache is not enough)
      5. open F-Droid and in Settings -> Repositories check if the AXP.OS Stable repo is there and enabled
      6. optional: activate the “Cutting Edge” repository

      F-Droid

      In order to remove the current outdated Divest F-Droid repositories you have to:

      1. long press the F-Droid icon
      2. choose App info
      3. choose Storage & Cache
      4. choose Clear Storage (Cache is not enough)
      5. open F-Droid and in Settings -> Repositories check if
        1. the Divest repos are gone
        2. the following repos must be there (all disabled): Molly, Molly FOSS, nailyk, Threema, FUTO, Cromite, IzzyOnDroid

      Mull Browser

      If you have installed the Divest Browser Mull it is strongly advised to uninstall it immediately as it will not receive any updates and is deprecated.

      Besides the security focused AOSmium Browser provided by the AXP.OS project there are other e.g. more privacy focused alternatives.
