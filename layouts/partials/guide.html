Fingerprint information

On boot you will see a fingerprint or "ID" which ensures the AVB signing key used is trusted.

Some devices print a minimal ID of 8 chars, while others print the whole digest. For more details and example pictures see here.

This fingerprint is unique for each device and flavor(!) but won't change during updates (at least not without a notice).

Here are both ones for {{ .codename }}.

If you see a different ID during boot you should immediately request support and stop using the device!
