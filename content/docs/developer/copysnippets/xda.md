[HEADING=1][CENTER][IMG]https://avatars.githubusercontent.com/u/139685517?s=200&v=4[/IMG][/CENTER][/HEADING]
[HEADING=1][CENTER]AXP.OS (short for "Advanced XPerience OS")[/CENTER][/HEADING]
[HEADING=2][CENTER]is a more private and secure mobile operating system that is based on AOSP & LineageOS and has emerged from the well-known but discontinued [I]DivestOS[/I] project.[/CENTER][/HEADING]
[CENTER]
In particular AXP.OS aims to support devices that would otherwise no longer receive any (Android/Kernel) updates and are therefore easily vulnerable.
All this is based on a best-effort principle, also because outdated devices no longer receive updates for proprietary firmware and are therefore insecure by definition.
AXP.OS at least [I]tries[/I] to close all the gaps that are possible.

In addition to this main goal, this project attempts to strike a balance between a

[B]privacy and
security-oriented[/B]
yet [B]usable[/B]

operating system - not least for [I]advanced[/I] users.

Read all about [B]AXP.OS[/B] on its [URL='https://axpos.org']homepage[/URL]
