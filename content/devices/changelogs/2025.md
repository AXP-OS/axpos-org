#### `ASB patch level`

Each month Google releases an Android Security Bulletin ("ASB") which contains important patches and marked with 2 different patch dates ([details](https://source.android.com/docs/security/bulletin/2025-01-01#Common-questions-and-answers)).

The following explains their meaning for AXP.OS:

|Patch date|STOCK OS|AXP.OS|
|-|-|-|
|`YYYY-MM-01`|Android platform fixes|Android platform fixes|
|`YYYY-MM-05`|Upstream Linux kernel fixes,<br/>Fixes from SOC manufacturers|Upstream Linux kernel fixes<br/>Fixes from SOC manufacturers*|

> [!IMPORTANT]
> - Fixes from SOC manufacturers can be provided for modern (i.e. still vendor supported) devices only. Many devices get these updates for a short period of time only.
> - Fixes from SOC manufacturers are always bound to the Android version of the AXP.OS version (_i.e. if AXP.OS is A13 and there are A14 SOC patches they cannot be applied_).

### This update requires manual interaction!

#### F-Droid

In order to remove the current outdated Divest F-Droid repositories you have to:
1. long press the F-Droid icon
1. choose `App info`
1. choose `Storage & Cache`
1. choose `Clear Storage` (_Cache_ is not enough)
1. open F-Droid and in `Settings` -> `Repositories` check if
   1. the Divest repos are **gone**
   1. the following repos must be there (all _disabled_): `Molly, Molly FOSS, nailyk, Threema, FUTO, Cromite, IzzyOnDroid`

#### Mull Browser

If you have installed the Divest Browser **Mull** it is strongly advised to uninstall it **immediately** as it will not receive any updates and is deprecated.

Besides the _security_ focused [AOSmium](/Browser) Browser provided by the AXP.OS project there are other e.g. more _privacy_ focused [alternatives](https://github.com/pluja/awesome-privacy?tab=readme-ov-file#android--ios-1).
