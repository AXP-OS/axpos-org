{{< callout emoji="💡" type="info" >}}
*_[AVB v1.0](/docs/knowledge/verifiedboot/#avb-10) is splitted into 2 parts: boot signing/verification and dm-verity (checksum verification of critical partitions).<br/>The _boot_ verification is part of the bootloader and so widely independent from the used/flashed Android version but is required for re-locking such a device (e.g. cheeseburger + dumpling).<br/>dm-verity on the other hand requires the kernel to mount partitions in a specific manner and this requires Android 10 or lower as the relevant code has been removed in Android 11.<br/>**In other words AVB v1.0 is [useless](/docs/knowledge/verifiedboot/#details) on A11 and later.**_
{{< /callout >}}

### This update requires manual interaction!

#### Magisk (Pro flavor)

To fix the [endless-request-loop](https://github.com/sfX-android/android_vendor_extendrom/wiki/FAQ#warning-never-patchinstall-magisk-when-asked-warning) you need to
1. Open Magisk
2. let it download the app
3. Open Magisk once again:
    - you will still see the infamous request about "Additional requirements need to be installed"
    - choose yes to allow this installation once again
    - the device will auto-reboot
    - 🚨WARNING🚨 if you get asked to [PATCH the boot image (see the screenshot in "Never PATCH/INSTALL Magisk when asked")](https://github.com/sfX-android/android_vendor_extendrom/wiki/FAQ#warning-never-patchinstall-magisk-when-asked-warning) STOP here, then the new fix does **not** work for you
4. once rebooted: open Magisk again.. no popup should be shown anymore! 🎉

#### F-Droid

Two AXP.OS F-Droid repositories have been prepared which will receive several apps in the future. Main purpose is deploying out-of-band updates, e.g. for the System Webview but also provide apps build/made by the AXP.OS project. See issue [#98](https://code.binbash.rocks/AXP.OS-public/issue-tracker/issues/98) for details and process. At the moment of writing there is only the AOSmium Browser available while this will change during the next weeks when the CI/CD scripts will be extended to push builds also to the F-Droid repos.

There are 2 repos available: **Stable** (roughly tested) and **Cutting Edge** (fully untested). If you enable _Cutting Edge_ be aware that it may contain unstable/broken/incomplete applications (however, you can choose which repository you prefer for each application).

In order to receive the new AXP.OS repositories you can either reset the F-Droid app or add it manually.

> [!IMPORTANT]
> _Due to a config mistake all Slim builds will receive this update with the **next** build first but don't worry you can still add them manually!_

**Manually:**
1. _Stable:_
    - open [https://apps.axpos.org/repo/](https://apps.axpos.org/repo/) and scan the code from your phone
1. _Cutting Edge:_
    - open [https://cutting-apps.axpos.org/repo/](https://cutting-apps.axpos.org/repo/) and scan the code from your phone

**By resetting F-Droid:**
1. long press the F-Droid icon
1. choose `App info`
1. choose `Storage & Cache`
1. choose `Clear Storage` (_Cache_ is not enough)
1. open F-Droid and in `Settings` -> `Repositories` check if the AXP.OS **Stable** repo is there and _enabled_
1. **optional:** activate the _"Cutting Edge"_ repository

### This update requires manual interaction!

#### F-Droid

In order to remove the current outdated Divest F-Droid repositories you have to:
1. long press the F-Droid icon
1. choose `App info`
1. choose `Storage & Cache`
1. choose `Clear Storage` (_Cache_ is not enough)
1. open F-Droid and in `Settings` -> `Repositories` check if
   1. the Divest repos are **gone**
   1. the following repos must be there (all _disabled_): `Molly, Molly FOSS, nailyk, Threema, FUTO, Cromite, IzzyOnDroid`

#### Mull Browser

If you have installed the Divest Browser **Mull** it is strongly advised to uninstall it **immediately** as it will not receive any updates and is deprecated.

Besides the _security_ focused [AOSmium](/Browser) Browser provided by the AXP.OS project there are other e.g. more _privacy_ focused [alternatives](https://github.com/pluja/awesome-privacy?tab=readme-ov-file#android--ios-1).
