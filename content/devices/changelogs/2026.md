## 2026.001

|Section|Comment|
|:-:|-|
|🪩🚨| New AXP.OS build id format: `YYYY.xxx` [(details & background)](/docs/knowledge/faq/#meaning-of-the-axpos-build-id)|
|🪩| AXP.OS _build id_ + _flavor_ now shown in:<br/>`Android Settings -> Info/About Phone -> Android Version (touch to open) -> AXP.OS version`|
|🪩| AXP.OS _build id_ is now also shown in **recovery**|
|🪩🚨| New AXP.OS patch level added: `YYYY-MM-03`, this also changes the meaning of `-01` and `-05` [(details)](/docs/knowledge/patchlevels/#the-axpos-patch-level)|
|🪩🚨| New AXP.OS patch level info for every device added [(check your device)](/devices)|
|🪩🚨| AXP.OS patch level _[(now depends per device)](/docs/knowledge/patchlevels/#the-axpos-patch-level)_|
|🪩🚨| Finalized [A15 move](https://code.binbash.rocks/AXP.OS-public/issue-tracker/issues/94)|
|🪩| AXP.OS patch level: **2026-02-**[01/03/05](/docs/knowledge/patchlevels/#the-axpos-patch-level) _(check [your device](/devices)_)
|🪩| Website adjustments to reflect the above changes|
|🪩| OTA, recovery, fastboot, factory downloads: replaced `-dos-` with `-PRO-` in filename|
|🪩| Moved sources from codeberg.org to git.disroot.org (github can be considered outdated)|
|🪩| Many background changes to automate bringing up new devices/flavors incl. optimizing the whole process|
