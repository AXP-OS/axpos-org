|🪩| added the corresponding test results issue link for each _build+device_ to versioning repo (e.g. [sargo-pro](https://code.binbash.rocks/AXP.OS/axp_versioning/src/tag/2026.002/sargo_pro.md))|
|🪩| Pro: fixed an issue that prevented the manual update of MicroG _(signature -> presigned)_|
|🪩| A15: re-implement **_Internet_ permission**|
|🪩| A15: re-implement **_Sensors_ permission**|
|🪩| A15: New toggle: `Privacy -> Allow Sensors permission to apps by default` _(see [News](/news/#android-15-is-there-))_|
|🪩| A15: APK installation prompt added: `Allow Network permission` _(see [News](/news/#android-15-is-there-))_|
|🪩| A15: Support AVB + Bootloader relock on legacy devices _(see [News](/news/#android-15-is-there-))_|
|✨| Android 15: [OnePlus 6](/devices/oneplus/enchilada) (_Pro_ flavor)|
|✨| Android 15: [OnePlus 6](/devices/oneplus/enchilada) (_Slim_ flavor)|
|🚨| EOL for Android **13** on [OnePlus 6](/devices/oneplus/enchilada), upgrade to Android 15 is required: [MRU (guide)](/MRU)|

{{< callout emoji="🚨" type="error" >}}
For all **A15** devices being upgraded from an earlier ***A15*** version of AXP.OS to `2026.002`, the newly added `Network` permission must be manually added for each _existing_ app that requires network access:<br/>`Long press app icon > Select "(i)" or "App info" > Permissions > Select "Network" and choose "Allow"`<br/>For more information, see [here](/news/#new-features).
{{< /callout >}}

{{< callout emoji="💡" type="info" >}}
Please note that all updates will be tracked by the `axp_versioning` repo from now on. Check the link in the above table.
{{< /callout >}}
